MODULE 12 — Hunting Web Shells & C2
40 Practice Questions

1. What is a web shell?
    √ A server-side script that provides unauthorized remote command capability through web requests
    • A browser's normal command history
    • A firewall rule allowing HTTPS
    • A database of valid user passwords

2. Why do web shells commonly use HTTP or HTTPS?
    • Web protocols prevent all forensic analysis
    • They automatically bypass every access control
    • A SIEM cannot collect web access logs
    √ Their requests can blend into ordinary web-server traffic

3. Which sequence best describes a typical web-shell attack?
    • Backup → patch → reboot → certify
    • Authenticate → change password → close sessions
    √ Exploit or upload → write script → request script → execute commands
    • Capture packets → delete logs → install antivirus

4. A server-side script passes a request parameter directly to an operating-system command function. What is the concern?

    √ Request-controlled input may cause command execution on the server

    • The request automatically requires Domain Admin approval

5. A command executed through a web shell returns www-data. What does this most directly indicate?
